# Release Notes - v1.0

## Password Requirements
- **Added** a minimum length requirement of 10 characters for passwords. This helps improve security by reducing the likelihood of weak or guessable passwords.

## Email Validation
- **Added** validation to ensure emails contain both `@` and `.`. This ensures emails are in a valid format, which is important for proper email handling and delivery.

## Vowel Counting
- **Updated** the vowel counting functionality to include both lowercase and uppercase vowels. This provides a more accurate count of vowels in text, which can be useful for various text analysis tasks.
